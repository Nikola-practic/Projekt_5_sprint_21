# Projekt_5_sprint_21

Автотесты для сервиса Stellar Burger.
Это космический фастфуд: можно собрать и заказать бургер из необычных ингредиентов.

Задание.
Требуется проверить:
1. Регистрация:
- Успешную регистрацию. 
- Поле «Имя» должно быть не пустым; в поле Email введён email в формате логин@домен: например, 123@ya.ru. 
- Минимальный пароль — шесть символов.
- Ошибку для некорректного пароля.

2. Вход:
- вход по кнопке «Войти в аккаунт» на главной,
- вход через кнопку «Личный кабинет»,
- вход через кнопку в форме регистрации,
- вход через кнопку в форме восстановления пароля.

3. Переход в личный кабинет: 
- переход по клику на «Личный кабинет»,
- переход по клику из личного кабинета на "Конструктор",
- переход по клику  из личного кабинета на логотип "Stellar Burgers".

4. Выход из аккаунта:
- выход по кнопке «Выйти» в личном кабинете.

5. Раздел «Конструктор»:
- работают переходы к разделам:
«Булки»,
«Соусы»,
«Начинки».
